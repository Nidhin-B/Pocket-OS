# Pocket-OS

**A lightweight Android launcher with a customizable pixel-LCD dashboard, app library, and retro themes.**

Give your home screen a retro pixel-display look with Pocket OS. Enjoy a customizable dashboard, app library, and classic LCD-inspired design.

## Features

### Make Your Home Screen Yours
- 16 color palettes, each with dark and light versions
- Custom colors and named themes
- Customizable clock, date, and battery display
- Favorites and recent apps
- App Library shortcut
- Custom wallpaper selection
- Adjustable app icon size

### Find and Manage Your Apps
- Browse installed apps in the searchable App Library
- Filter apps
- Manage favorites and hidden apps with long-press actions
- Launch apps directly from the dashboard or library

### Designed for a Retro Feel
- Pixel-style typography
- Classic LCD-inspired layout
- Optional CRT scanlines
- Haptics and motion settings
- Smooth transitions between Home, Library, and Settings

## Compatibility

- **Platform:** Android
- **Minimum Android Version:** Android 8.0 (Oreo)
- **Format:** APK
- **Category:** Personalization / Launcher

## Installation

1. Download the Pocket OS APK.
2. Open the downloaded file.
3. Allow installation from the selected source if prompted.
4. Install Pocket OS.
5. Open the app.
6. Select Pocket OS as your default Home app in Android settings.
